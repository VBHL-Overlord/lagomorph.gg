# lagomorph.gg

Placeholder site for Lagomorph Games, served by GitHub Pages from `main` at https://lagomorph.gg.

Plain static files, no build step. Edit `index.html`, push to `main`, and Pages redeploys in about a minute.

- `CNAME` binds the custom domain; don't delete it.
- Logo and icons are derived from the Sep 9, 2026 logo render (1254×1254 PNG).
- `art-samples/` is a password-protected page of sample art for studios under NDA. It is built, encrypted, in the admin repo (`lagomorph-admin/tools/build_sample_site.mjs --final`) and copied here; don't edit it by hand. `robots.txt` keeps crawlers out of it.
